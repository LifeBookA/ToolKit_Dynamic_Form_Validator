# 🛠️ راهنمای نصب و پیکربندی

این مستندات نحوه نصب، پیکربندی و عیب‌یابی اولیه کتابخانه **Dynamic Form Validator** را توضیح می‌دهد.

## پیش‌نیازها

- **PHP نسخه 8.2 یا بالاتر**
- فعال بودن اکستنشن‌های پیش‌فرض PHP (مانند `json`, `filter`, `date`)
- دسترسی نوشتن به فایل‌ها (در صورت استفاده از قانون `unique` با فایل JSON)

---

## روش‌های نصب

### ۱. نصب دستی (بدون Composer)

این روش برای پروژه‌هایی که از Composer استفاده نمی‌کنند ایده‌آل است.

1. **کپی فایل‌ها:**
   کل پوشه `src` را از مخزن دانلود کرده و در ریشه پروژه خود کپی کنید.
   ```
   YourProject/
   ├── src/
   │   ├── Autoloader.php
   │   ├── Bootstrap.php
   │   └── Validator/
   └── index.php
   ```

2. **بارگذاری اولیه:**
   در فایل اصلی پروژه (مثلاً `index.php` یا `public/index.php`)، فایل `Bootstrap.php` را فراخوانی کنید:
   ```php
   <?php
   require_once __DIR__ . '/src/Bootstrap.php';
   
   // اکنون می‌توانید از کلاس‌ها استفاده کنید
   use Toolkit\Validator\Validator;
   ```

### ۲. نصب با Composer (PSR-4)

اگر پروژه شما از Composer استفاده می‌کند:

1. **تنظیم `composer.json`:**
   بخش `autoload` را به صورت زیر تنظیم کنید:
   ```json
   {
       "autoload": {
           "psr-4": {
               "Toolkit\\": "src/"
           }
       }
   }
   ```

2. **به‌روزرسانی اتولودر:**
   دستور زیر را در ترمینال اجرا کنید:
   ```bash
   composer dump-autoload
   ```

3. **استفاده:**
   ```php
   <?php
   require 'vendor/autoload.php';
   
   use Toolkit\Validator\Validator;
   ```

## پیکربندی محیط

فایل `src/Bootstrap.php` به صورت خودکار تنظیمات زیر را اعمال می‌کند:
- نمایش خطاها در محیط توسعه (`display_errors = On`)
- گزارش‌دهی کامل خطاها (`error_reporting = E_ALL`)
- تنظیم منطقه زمانی پیش‌فرض (`UTC`)

**تغییر تنظیمات:**
اگر می‌خواهید تنظیمات خاصی اعمال کنید، می‌توانید قبل از فراخوانی `Bootstrap::init()` (در صورت وجود متد init در نسخه شما) یا بعد از آن، تنظیمات دلخواه `php.ini` یا `ini_set` را اعمال کنید.

## ساختار پوشه‌ها

شناخت ساختار پوشه‌ها برای عیب‌یابی و توسعه ضروری است:

```
src/
├── Autoloader.php          # بارگذار خودکار کلاس‌ها
├── Bootstrap.php           # نقطه شروع و تنظیمات محیط
└── Validator/
    ├── Contracts/          # اینترفیس‌ها (RuleInterface)
    ├── Rules/              # کلاس‌های قوانین اعتبارسنجی
    ├── Exceptions/         # کلاس‌های استثنا
    ├── Config/             # تنظیمات و پیام‌های پیش‌فرض
    ├── Helpers/            # توابع کمکی
    ├── Result/             # کلاس نتیجه اعتبارسنجی
    └── Validator.php       # کلاس اصلی اعتبارسنج
```

## عیب‌یابی مشکلات رایج

### خطای "Class not found"
- **علت:** فایل `Bootstrap.php` فراخوانی نشده یا مسیر آن اشتباه است.
- **راه حل:** مطمئن شوید `require_once 'src/Bootstrap.php';` در ابتدای اسکریپت اصلی وجود دارد.

### خطای "Namespace declaration..."
- **علت:** وجود کد یا فضای خالی قبل از تگ `<?php` یا دستور `declare(strict_types=1)`.
- **راه حل:** فایل‌ها را بررسی کنید تا اولین خط حتماً `<?php` باشد.

### کار نکردن قانون `unique`
- **علت:** عدم دسترسی نوشتن به فایل JSON یا مسیر اشتباه.
- **راه حل:** مسیر فایل JSON را نسبت به ریشه پروژه بررسی کنید و سطح دسترسی (Permissions) فایل را چک کنید.

### نمایش داده نشدن خطاها
- **علت:** غیرفعال بودن `display_errors` در سرور تولید.
- **راه حل:** در محیط توسعه، اطمینان حاصل کنید که `error_reporting(E_ALL)` و `ini_set('display_errors', '1')` فعال هستند.
